1.Galería Visual

 Descripción del proyecto

Este proyecto consiste en una galería web estática donde se presentan distintos recursos visuales organizados en formato de tarjetas.
Cada elemento de la galería incluye una imagen, un título y una breve descripción.
El diseño utiliza HTML y CSS, aplicando colores, gradientes, imágenes de fondo y efectos de transparencia para mejorar la presentación visual.
 
2.Instrucciones para ver el proyecto en local

Para ver el proyecto en tu computador de forma local, sigue estos pasos:

Descarga o clona este repositorio en tu computador.

Abre la carpeta del proyecto.

Haz doble clic sobre el archivo index.html.

El proyecto se abrirá automáticamente en tu navegador web.

No es necesario instalar programas adicionales.

 Decisiones de diseño

 Elección de la paleta de colores

La paleta de colores fue elegida para darle a la página un estilo llamativo y con energía, ya que se trata de una galería visual de personajes.
Se utilizaron colores fuertes para resaltar los elementos principales como los items de la galería y el banner, y colores más claros para el texto y el fondo, buscando un buen contraste y una lectura cómoda.
Los colores se definieron usando variables en CSS (:root), lo que permitió mantener un mismo estilo en toda la página y facilitar cambios futuros sin modificar todo el código.

 Diseño y uso de gradientes

Los gradientes se aplicaron principalmente en el encabezado (header) y pie de pagina (footer) para evitar un diseño plano y hacer que el título principal y el pie de pagina destaque desde el primer momento.
El gradiente ayuda a guiar la atención del usuario y a separar visualmente el encabezado y el pie de pagina del resto del contenido.
Además, en algunas secciones se combinó el uso de imagen de fondo con efectos visuales para lograr una mejor presentación sin sobrecargar el diseño.

 Uso y optimización de imágenes

Las imágenes utilizadas están en formato WEBP, lo que ayuda a reducir el peso de los archivos y mejorar el tiempo de carga de la página.
En la galería, las imágenes se ajustan usando object-fit: contain, lo que evita deformaciones y mantiene una proporción adecuada en todos los items.
También se aplicaron imágenes como fondo en algunas secciones mediante CSS, configurando correctamente propiedades como background-size, background-position y background-repeat para asegurar una correcta visualización en distintos tamaños de pantalla.
